# Snake-Ladder-2P

Animated 2-player Snake & Ladder browser game.

Features
- 2 players (local, hotseat)
- Smooth per-square token movement animations
- Dice rolling animation
- Slide animations for snakes and ladders
- Exact-to-100 win rule
- Responsive layout

How to run

1. Clone the repository:

   git clone https://github.com/624183-NITAP/snake-ladder.git
2. Open `index.html` in a modern browser (Chrome, Edge, Firefox, Safari).

Contributing
